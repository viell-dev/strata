# Contributing

This repository holds documentation only. Code contributions belong in the individual crate
repositories, which have their own contribution policies.

## Issues

Open an issue here for anything that spans more than one crate:

- design questions and suggestions for the ecosystem as a whole,
- fixes and improvements for the documents in this repository,
- naming questions for a package you want to build on Strata.

Crate bugs and feature requests go to that crate's repository. If in doubt, open it here and we
will move it where it belongs.

## Naming your package

The `strata-*` prefix on crates.io is open to anyone, so we can only ask nicely. If you are
publishing something built on Strata, `strata-ext-*` is recommended for community packages; it
keeps the plain `strata-<language>` names free for the official ones. Naming guidelines beyond that
are still being worked out, so open an issue before you claim a name and we will figure it out
together.

## Documentation changes

Small fixes like typos, broken links, or unclear wording can go straight to a pull request. For
anything bigger, open an issue first so we can agree on the direction.

Keep Markdown wrapped at 100 columns and match the style of the existing documents.
